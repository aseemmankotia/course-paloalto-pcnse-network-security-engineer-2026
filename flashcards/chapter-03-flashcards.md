## Chapter 3: App-ID and User-ID for Safe Application Enablement — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | What are the three techniques App-ID uses to identify traffic? | Pattern-based application signatures, protocol decoding, and heuristics (for evasive apps like P2P/tunneling). Exam tip: heuristics are applied last, only when the first two can't identify the app. |
| 2 | What happens to Content-ID inspection when Application Override is applied to a session? | Content-ID (antivirus, vulnerability protection, WildFire, URL filtering) does NOT run at all on that session — the app identity is locked in and further App-ID/Content-ID processing is skipped. Exam tip: major security risk, common exam trap. |
| 3 | Which User-ID agent type runs on the firewall itself with no separate Windows server install? | PAN-OS integrated (agentless) User-ID agent — polls domain controllers directly. Exam tip: 'agentless' refers to no external server, not no software at all. |
| 4 | Which User-ID method is required when many users share one IP address, such as on Citrix/RDS? | Terminal Server (TS) agent — allocates a unique port range per user session for identification. Exam tip: needed whenever a single source IP represents multiple concurrent users. |
| 5 | What is Captive Portal used for in User-ID? | Active authentication (NTLM, browser challenge, or form-based) used as a fallback to positively identify a user when passive mapping methods fail. Exam tip: it's active auth, unlike passive server monitoring/log parsing. |
| 6 | How does the firewall learn the real client IP for users behind a forward proxy? | Enable trust of the X-Forwarded-For (XFF) header from the specific trusted proxy in User-ID settings. Exam tip: required whenever the firewall otherwise only sees the proxy's IP. |
| 7 | Where is LDAP Group Mapping configured in PAN-OS, relative to User Mapping? | Device > User Identification > Group Mapping Settings — a separate tab/config from User Mapping (IP-to-user), using its own LDAP server profile. Exam tip: the exam tests that these two are distinct configurations. |
| 8 | Which dynamic update delivers new App-ID signatures? | Applications and Threats content update (or Applications-only without a Threat Prevention license). Exam tip: App-ID is continuously updated, not a static database. |
| 9 | What is the key security risk of using Application Override on a custom port? | Traffic bypasses further App-ID checks AND all Content-ID scanning for that session. Exam tip: override changes classification but disables the deeper inspection students assume still runs. |
| 10 | Windows-based User-ID agent vs PAN-OS integrated agent — key difference? | Windows-based agent installs on a dedicated Windows server and monitors AD security logs/WMI probing; PAN-OS integrated agent runs directly on the firewall. Exam tip: choose Windows agent for large/distributed AD environments needing a dedicated collector. |
| 11 | Where does group mapping pull group membership data from? | An LDAP directory (e.g., Active Directory) via a dedicated LDAP server profile, configured independently of IP-to-user mapping. Exam tip: both configs are required together for group-based policy to function. |
| 12 | When does App-ID fall back to heuristics? | Only when pattern-based signatures and protocol decoders fail to identify an evasive/unknown app (e.g., encrypted P2P or tunneling traffic). Exam tip: heuristics is the last-resort technique, not the first check. |
