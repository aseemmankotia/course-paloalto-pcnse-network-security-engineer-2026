# Chapter 3 Lab: App-ID and User-ID for Safe Application Enablement

**Estimated time:** 15 minutes

## Exercise

Read-and-understand walkthrough: review a User-ID mapping table and a captive portal configuration scenario, then determine which mapping method would correctly identify a user behind a proxy

## Key takeaway

App-ID identifies the application while User-ID maps sessions to identities and groups — both must be correctly configured and neither should be bypassed carelessly, since doing so removes downstream Content-ID protections.
