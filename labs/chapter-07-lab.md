# Chapter 7 Lab: Panorama: Templates, Template Stacks, and Device Groups

**Estimated time:** 15 minutes

## Exercise

Read-and-understand walkthrough: given a template stack with three templates and overlapping interface settings, determine which template's setting applies based on stack order

## Key takeaway

Panorama separates network/device configuration (templates and template stacks) from policy and objects (device groups), and both commit AND push are required to actually deploy changes to managed firewalls.
