# Chapter 5 Lab: Threat Prevention: Antivirus, Anti-Spyware, and Vulnerability Protection

**Estimated time:** 12 minutes

## Exercise

Read-and-understand walkthrough: inspect a default Anti-Spyware profile's severity-to-action mapping table and identify which severities only alert instead of block

## Key takeaway

Antivirus, Anti-Spyware, and Vulnerability Protection profiles enforce Content-ID threat scanning, but default actions are often alert-only, so tuning severity-based actions is a required engineering step, not an assumption.
