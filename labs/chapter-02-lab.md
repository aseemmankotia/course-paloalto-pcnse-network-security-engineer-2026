# Chapter 2 Lab: Security Policy, NAT, and Zone/Interface Design

**Estimated time:** 20 minutes

## Exercise

Read-and-understand walkthrough: given a sample rulebase with 5 security rules and 2 NAT rules, manually determine which rule matches a described session and why, including identifying a shadowed rule

## Key takeaway

Security policy is first-match top-down evaluation using post-NAT zones with pre-NAT addresses, so correct rule ordering and understanding NAT interaction are essential for both real deployments and the exam.
