# Chapter 8 Lab: PAN-OS Upgrades, High Availability, and Configuration Management

**Estimated time:** 15 minutes

## Exercise

Read-and-understand walkthrough: given a firewall running PAN-OS 9.1 that needs to reach 11.1, map out the required sequential upgrade steps through intermediate major releases

## Key takeaway

Operating PAN-OS reliably requires disciplined sequential upgrades, a clear understanding of active/passive vs active/active HA trade-offs, and treating the running configuration — not the candidate — as the true backup source.
