## Chapter 11 Cheat Sheet: Exam Pacing & Strategy

### Time Budget Plan

| Phase | Time | Action |
|---|---|---|
| First pass | ~55-60 min | Answer every question; flag anything without a clear leading answer after ~90 sec |
| Second pass | ~10-12 min | Revisit only flagged questions, in order flagged |
| Final buffer | ~5-10 min | Sanity-check flagged answers; do not open new questions from scratch |

**Core rule:** every question = equal weight. Never leave a question blank to 'save time' for a flagged one — a guessed answer beats a blank answer every time.

### Flag Criteria

| Flag it if... | Don't flag if... |
|---|---|
| No leading answer emerges after ~90 sec | You have a confident answer, even if unsure of a distractor |
| Two options both look technically valid | Only one option is technically valid |
| The question requires re-reading the stem twice | The stem is a single, clear sentence |

### Elimination Technique — Qualifier Words Decide

| Stem qualifier | What it eliminates |
|---|---|
| "least operational overhead" | Options requiring new infrastructure/redesign |
| "most secure" | Options that partially cover the requirement |
| "minimum number of rules/steps" | Options using multiple rules where one suffices |
| "BEST" (all caps) | Signals two+ technically valid options exist — find the qualifier |

### Keyword → Feature/Domain Recognition

| Scenario phrase | Points to |
|---|---|
| "centralized management/logging across many firewalls" | Panorama |
| "both firewalls process traffic, no session loss on failover" | Active/Active HA |
| "decrypt general traffic, exempt certain categories" | SSL Decryption exclusion by URL Category |
| "allow app regardless of port, block unknown on that port" | App-ID rule with 'application default' service |
| "alarm before mitigation kicks in" (flood scenario) | Zone Protection Profile Alarm Rate threshold |

### Reading Order Rule
Read the FULL stem, underline every qualifier/constraint word mentally, THEN read the options. Reading options first causes anchoring on the first plausible-looking choice and missing a later constraint clause.

### Final Review Rule
Reserve the last ~10 minutes strictly for flagged questions. Do not re-analyze from zero — trust your first-pass elimination unless you spot a stem detail you missed the first time.
